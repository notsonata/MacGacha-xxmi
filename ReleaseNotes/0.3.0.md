# MacGacha 0.3.0 — XXMI update 1

## Versions

- MacGacha **0.3.0**, build **5**
- XXMI Libraries **1.2.3** · SRMI **2.4.3**
- HSR compatibility package **2.4.3-macgacha.3**
- Experimental ZZMI configuration **1.5.2**. ZZZ injection currently crashes the game, see below

## Mods

- Finished mod sessions are reclaimed after saving user settings. Startup cleanup removes abandoned sessions while protecting active games and unresolved recovery.
- **Apply Mods to Running Game** updates the enabled mods in the active session. Switch back to the game and press **F10** (or **fn+F10**) to reload. Changes are applied only when requested.
- Mod files are copied into independently owned snapshots. Optional APFS cloning is deferred.
- Restored the embedded fonts required by the XXMI overlay and added resource checks to the package verifier.
- Updated the shared XXMI core to the latest stable Libraries release and the experimental ZZMI configuration to 1.5.2. XXMI Launcher UI is not included.

## Fixes

- Games installed on an external drive become available as soon as the drive is connected, without restarting MacGacha. Removing the drive marks them unavailable again.

## MacGacha updates

- Includes upstream MacGacha 0.3.0: signed dependency catalogs, managed dependency updates and rollback, patch downloads, pre-download, Game Mode, frame-rate options and surround audio.
- Includes upstream runtime, game-startup and download-throughput fixes.
- Mod injection remains restricted to the previously verified Wine/D3DMetal bundle. Newer upstream Wine builds are not automatically treated as mod-compatible.

## Updating

Replace the app, then use **XXMI → Update** to activate the bundled HSR compatibility package. Your mod library and saved settings are retained.

This fork uses manual release downloads. The app is ad-hoc signed, not Apple-signed or notarized.

## Verification limits

Session cleanup and live mod publication have synthetic regression coverage. F10 delivery, repeated hot reload, and Game Mode with injection still require owner-run gameplay acceptance. ZZZ with injection enabled currently crashes shortly after launch, because the game's anti-tamper module detects the injected XXMI module. Keep Mods off for Zenless Zone Zero.
