# MacGacha 0.3.2 — XXMI update 1

## Versions

- MacGacha **0.3.2**, build **13** (fork tag `v0.3.2-xxmi.1`)
- XXMI Libraries **1.2.3** · SRMI **2.4.3** · ZZMI **1.5.2**
- HSR compatibility package **2.4.3-macgacha.4**
- ZZZ compatibility package **1.5.2-macgacha.2** (experimental)

## New

- **Zenless Zone Zero mods (experimental).** ZZMI now loads in Global ZZZ without the anti-tamper crash. Instead of being injected, ZZMI is placed as the prefix's `d3d11.dll` for one session. MacGacha records every file and registry value it changes and restores them when the game exits, or on the next start after a crash.
- ZZZ has its own mod library, ZZMI package and saved settings, separate from Star Rail.
- **Apply Mods to Running Game** now sits next to **Done** in the XXMI panel and works for both games.
- Mods can be sorted in the XXMI panel.
- After each ZZZ session, the 3DMigoto log is copied next to the session log, so mod problems can be diagnosed after the game closes.
- XXMI packages can be updated without a new app. A standalone `XXMI-ZZZ-…zip` is now published alongside `XXMI-HSR-…zip`. Extract it and choose its folder in **XXMI → Import Package…**.
- **Update** appears only when the built-in package is newer. If you imported a newer package, MacGacha shows **Use Built-in …** with the exact version instead of quietly downgrading.
- Packages can declare the oldest MacGacha build they work with. An older app refuses to install or launch them and asks you to update MacGacha.

## Fixes

- SRMI no longer crashes the game when a shader can't be disassembled. That shader is skipped instead (HSR package 2.4.3-macgacha.4).

## Changes

- Includes upstream MacGacha 0.3.1 and 0.3.2. Highlights:
  - games on external drives and **Move…** to another folder or drive
  - a **Storage** panel
  - **Reset Wine Prefix**
  - Metal HUD options
  - play time
  - notifications
  - a download speed limit
  - opt-in wish history export
  - starting a game from the Dock
  - MacGacha Wine 11.22
- The fork's own fix for external drives is replaced by upstream's more complete one.

## Limitations

- Mods still need **D3DMetal · Wine 11.20 / GPTK 4.0b3**. Wine 11.22 is upstream's new recommendation, but MacGacha keeps a game on the mod-compatible runtime while its mods are on, and injection refuses other runtimes.
- ZZZ needs **DirectX 12 off**. In the game's graphics settings, keep **Character Quality** on High and set **High-Precision Character Resolution** to **Off**. Otherwise some modded characters render unmodded or as spiky shards.
- ZZZ mod support is experimental. Some mods have their own in-game menus with their own controls, for example right-click to click and drag.
- **Apply Mods to Running Game** and F10 reloads still need more gameplay testing. A character already on screen may need to be reloaded.
- Genshin Impact support (GIMI) is not planned.
- Rendering correctly says nothing about account safety. Mod injection may be treated as cheating.

## Install and update

Download the DMG from this release, replace the app, then open **XXMI → Update** for each game to activate its bundled compatibility package. Your mod libraries and saved settings are kept.

This fork uses manual release downloads. The app is ad-hoc signed, not Apple-signed or notarized.
